# [DEF-20261116-1609] Unversioned dashboard-chat.js Cache, Late-Load Lifecycle, and Flattened Nested Lists

- **Status:** `Resolved`
- **Opened:** 2026-11-16 16:02
- **Closed:** 2026-11-16 16:09
- **Component:** `aura-manager`
- **Scope:** `Framework & Config/Environment`
- **Symptom:** AI assistant replies persisted with valid multi-line Markdown rendered inside the dashboard chat overlay—both in loaded session history and in active chat sessions—as raw single-line text showing literal `###`, `**`, `-`, and `` ` `` delimiters, and indented nested list items were flattened into a single list level.
- **Root Cause:** `templates/index.html` loaded `dashboard-chat.js` (plus `dashboard-core.js`, `dashboard-runner.js`, and `dashboard-settings.js`) without a `?v=` cache-busting query string while Spring Boot served static JS without `no-cache`, allowing browsers that had cached an earlier `dashboard-chat.js` to execute stale code without `renderChatMarkdown` against freshly rendered `chat.html` (`class="text chat-markdown"`). In addition, `dashboard-chat.js` only triggered `renderChatMarkdown` on `DOMContentLoaded` (missing `document.readyState !== 'loading'`) and `htmx:afterSwap` scoped solely to `evt.detail.target` (missing `htmx:oobAfterSwap` / `htmx:afterSettle` and `document` fallback), while `buildMarkdownFragment` matched `/^\s*[-*]\s+/` without tracking leading indentation depth.
- **Detection Gap ("What did we miss?"):** `DashboardChatJsTest` previously invoked `buildMarkdownFragment` directly on a Node VM mock DOM with `readyState === 'loading'` and did not verify `index.html` cache-busting query parameters, non-loading initial `readyState`, `htmx:oobAfterSwap` / `htmx:afterSettle` swaps, or nested list indentation.
- **Resolution:** Added `?v=1.2.8` cache-busting query strings to `dashboard-core.js`, `dashboard-chat.js`, `dashboard-runner.js`, and `dashboard-settings.js` in `aura-manager/src/main/resources/templates/index.html`; updated `dashboard-chat.js` to run `renderChatMarkdown(document)` immediately when `document.readyState !== 'loading'` and on `htmx:afterSwap`, `htmx:oobAfterSwap`, and `htmx:afterSettle`; and replaced flat list parsing in `buildMarkdownFragment` with indentation-aware `parseListLine` / `appendListBlock`.
- **Safety Net Added:** Added `DashboardChatJsTest.testChatMarkdownReadyStateOobSwapAndNestedListsViaNode` (verifying immediate rendering when `readyState === 'complete'`, OOB/settle/detached-target HTMX swaps, and nested `<ul>`/`<ol>` generation) and `AuraTestDashboardControllerTest.testIndexTemplateIncludesCacheBustingVersionsForDashboardScripts` (verifying `?v=` cache-busters in `index.html`).
