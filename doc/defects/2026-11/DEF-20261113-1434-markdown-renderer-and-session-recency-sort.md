# [DEF-20261113-1434] Dashboard Chat Markdown Parsing Gaps, Hardcoded Code-Block Contrast, and Non-Recency Session Sorting

- **Status:** `Resolved`
- **Opened:** 2026-11-13 14:34
- **Closed:** 2026-11-13 14:34
- **Component:** `aura-manager`
- **Scope:** `Framework`
- **Symptom:** AI responses containing GFM tables, blockquotes, horizontal rules, underscore emphasis (`_italic_`), or links whose URLs include balanced parentheses (e.g. Wikipedia URLs) rendered as broken raw text; code blocks used hardcoded `rgba(15, 23, 42, 0.08)` contrast unsuitable across themes; and chat sessions sorted alphabetically instead of most-recently-updated first.
- **Root Cause:** [`dashboard-chat.js`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/resources/static/dashboard-chat.js) used a regex `\[[^\]]+\]\([^)]+\)` that terminated early on `)` inside URLs and lacked block parsers for `>`, `---`, tables, and `_italic_`; [`dashboard-styles.css`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/resources/static/dashboard-styles.css) lacked CSS variables on `.chat-markdown` code/table/blockquote styles; and [`ChatSessionDto`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/java/com/xceptance/aura/chat/dto/ChatSessionDto.java) + [`AuraChatSessionService`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/java/com/xceptance/aura/chat/service/AuraChatSessionService.java) tracked no `updatedAt` timestamp and sorted strictly by session name.
- **Detection Gap ("What did we miss?"):** Java unit tests only asserted that `th:utext` was absent without executing `dashboard-chat.js` against a DOM mock in Node, and `AuraChatSessionServiceTest` did not verify session ordering after `addMessage`.
- **Resolution:** Replaced the regex inline tokenizer in `dashboard-chat.js` with a balanced-parenthesis URL & word-boundary-aware scanner, added block renderers for blockquotes, GFM tables, and horizontal rules, updated `dashboard-styles.css` to use theme CSS variables and confirmation card styling, and added `ChatSessionDto.updatedAt` tracking (with `file.lastModified()` fallback for legacy files) sorted descending in `AuraChatSessionService.getSessions()`.
- **Safety Net Added:** [`DashboardChatJsTest`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/test/java/com/xceptance/aura/chat/DashboardChatJsTest.java) method `testMarkdownRendererAndSubmitGuardsViaNode` and [`AuraChatSessionServiceTest`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/test/java/com/xceptance/aura/chat/service/AuraChatSessionServiceTest.java) recency sort assertions.
