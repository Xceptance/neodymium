# [DEF-20261113-1433] Unbounded Model Cache, Unwired Gemini HTTP Options Timeout, and `@JsonProperty` Schema Enrichment Mismatch

- **Status:** `Resolved`
- **Opened:** 2026-11-13 14:33
- **Closed:** 2026-11-13 14:33
- **Component:** `aura-manager`
- **Scope:** `AI/Prompt & Framework`
- **Symptom:** Repeated configuration updates caused unbounded growth of cached `ChatModel` instances in `AuraChatModelFactory`; Gemini client initialization ignored configured timeout and custom `baseUrl` settings; and `AuraMcpToolCallbackProvider` failed to match `@McpToolParam` constraints onto schema properties annotated with `@JsonProperty` while silently swallowing enrichment exceptions.
- **Root Cause:** `AuraChatModelFactory.modelCache` used an unbounded `ConcurrentHashMap`, `createGeminiModel` omitted `HttpOptions` on `Client.builder()`, and `AuraMcpToolCallbackProvider.enrichInputSchemaWithMcpParams` used `Parameter.getName()` without checking `@JsonProperty.value()` and ignored exceptions inside an empty `catch` block.
- **Detection Gap ("What did we miss?"):** Factory unit tests only inspected single-provider creation without verifying cache eviction or `HttpOptions` timeout propagation, and schema enrichment tests only exercised methods whose Java parameter names matched serialized JSON property names.
- **Resolution:** Replaced `modelCache` in [`AuraChatModelFactory`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/java/com/xceptance/aura/chat/service/AuraChatModelFactory.java) with a synchronized bounded LRU `LinkedHashMap` (max 16 entries), wired `buildGeminiHttpOptions(timeout, baseUrl)` into Gemini `Client.builder()`, updated [`AuraMcpToolCallbackProvider`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/java/com/xceptance/aura/chat/service/AuraMcpToolCallbackProvider.java) to resolve `@JsonProperty` names before falling back to `Parameter.getName()`, and logged warnings when schema enrichment cannot inspect a method.
- **Safety Net Added:** [`AuraChatModelFactoryTest`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/test/java/com/xceptance/aura/chat/service/AuraChatModelFactoryTest.java) method `testGeminiTimeoutAppliedAndCacheBounded` and [`AuraMcpToolCallbackProviderTest`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/test/java/com/xceptance/aura/chat/service/AuraMcpToolCallbackProviderTest.java) method `testJsonPropertyAnnotationOverridesParameterNameInSchema`.
