# [DEF-20261113-1738] Premature Chat Input Wipe, Stuck Confirmation Buttons, Unscoped HTMX Error Cleanup, and Glob Markdown Corruption

- **Status:** `Resolved`
- **Opened:** 2026-11-13 17:38
- **Closed:** 2026-11-13 17:38
- **Component:** `aura-manager`
- **Scope:** `Framework`
- **Symptom:** Submitting a chat message wiped `#chatInput` after 10ms even if `/api/chat` subsequently failed (forcing users to retype prompts); clicking Confirm/Cancel left buttons permanently stuck in `"Confirming..."` / disabled state on network or HTTP errors; unrelated HTMX failures (e.g., `/api/status` polling errors) deleted active `.thinking-bubble` and `.optimistic-user-bubble` indicators in the chat pane; and Markdown containing multiple path globs (`tests/*.yaml and suites/*.yaml`), arithmetic (`2*3*4`), or inline code with asterisks inside emphasis (`*check \`foo*bar\` first*`) was misparsed as `<em>` / broken markup.
- **Root Cause:** [`dashboard-chat.js`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/resources/static/dashboard-chat.js) used a `setTimeout(..., 10)` in `clearChatInput` instead of waiting for `htmx:afterRequest` success, lacked error recovery for disabled confirmation buttons on `htmx:responseError`/`htmx:sendError`, and scanned for closing `*`/`**`/`_` without skipping backtick code spans or rejecting `/` / `\` path boundaries around single `*`. Meanwhile [`dashboard-core.js`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/resources/static/dashboard-core.js) lacked an `htmx:sendError` listener and unconditionally removed chat bubbles on every `htmx:responseError`.
- **Detection Gap ("What did we miss?"):** The existing `DashboardChatJsTest` Node harness only loaded `dashboard-chat.js` to test basic Markdown tags and empty-submit prevention, without loading `dashboard-core.js`, dispatching `htmx:afterRequest`/`htmx:responseError`/`htmx:sendError` lifecycle events, or testing glob/arithmetic/inline-code inputs.
- **Resolution:** Replaced timed input clearing in [`dashboard-chat.js`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/resources/static/dashboard-chat.js) with `htmx:afterRequest` clearing scoped to `/api/chat` (`status < 400`), added `restoreChatConfirmationButtons()` invoked on chat error events, added `skipInlineCodeSpan` and `isStarBoundaryBlockingChar` (`/`, `\`, alphanumeric/underscore) guards to the Markdown inline scanner, and updated [`dashboard-core.js`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/resources/static/dashboard-core.js) (`isChatHtmxRequest` + `handleChatRequestFailureCleanup` + `htmx:sendError`) so chat bubble cleanup and confirmation button recovery only trigger for `/api/chat*` or `#chatMessages`/`#chatContainer` requests.
- **Safety Net Added:** [`DashboardChatJsTest`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/test/java/com/xceptance/aura/chat/DashboardChatJsTest.java) glob/code-span assertions in `testMarkdownRendererAndSubmitGuardsViaNode` and full lifecycle test `testChatInputPreservationConfirmationRecoveryAndErrorScopingViaNode`.
