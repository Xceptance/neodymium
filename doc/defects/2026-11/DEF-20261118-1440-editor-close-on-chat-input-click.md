# [DEF-20261118-1440] Text Editor Closes on Click Inside AI Assistant Chat Input

- **Status:** `Resolved`
- **Opened:** 2026-11-18 14:40
- **Closed:** 2026-11-18 14:43
- **Component:** `aura-manager`
- **Scope:** `Framework`
- **Symptom:** In Aura Test Manager, when the text editor panel (`#editorPanel`) is open to view/edit test files (such as YAML playbooks or configuration files), clicking inside the Aura AI Assistant input textarea (`#chatInput`) or anywhere within the chat overlay causes the text editor to immediately close unexpectedly.
- **Root Cause:** In `aura-manager/src/main/resources/static/dashboard-editor.js` (lines 1726-1783), a global capturing click listener was registered on `document` via `document.addEventListener('click', ..., true)` to intercept user navigation while a file is open in the editor (warning the user about unsaved changes and closing the editor on navigation). The interceptor checked `const link = e.target.closest('a[href], [hx-get], [hx-post]')`. Because the chat prompt textarea `#chatInput` is nested within `<form class="chat-input-form" hx-post="/api/chat">`, clicking the textarea or submitting the prompt resolved to a truthy `link` having `hx-post`. Because `#editorPanel`, `#auraChatOverlay`, `.aura-chat-overlay`, and `.aura-chat-launcher` were not exempted from this navigation handler, the interceptor falsely interpreted clicking into the AI Assistant as navigating away from the page and called `closeEditor(true)`.
- **Detection Gap ("What did we miss?"):** The navigation interceptor was originally implemented to guard against traditional hypermedia navigation via sidebar links or page tabs. When the Aura AI Assistant chat overlay (`#auraChatOverlay`) was mounted globally in `index.html` and equipped with HTMX actions (`hx-post="/api/chat"`), integration tests did not simulate user interactions in the chat overlay while the text editor was active.
- **Resolution:** Updated `dashboard-editor.js` navigation click listener in `aura-manager/src/main/resources/static/dashboard-editor.js`:
  1. Added early guard `if (e.target.closest('.modal-overlay, .modal-card, #editorPanel, #auraChatOverlay, .aura-chat-overlay, .aura-chat-launcher')) return;` so clicks originating inside modals, the editor itself, or the AI Assistant chat overlay/launcher are completely ignored by the navigation interceptor.
  2. Added second guard `if (link.closest('#editorPanel, #auraChatOverlay, .aura-chat-overlay, .aura-chat-launcher')) return;` ensuring that any anchor or HTMX form element (`[hx-post]`, `[hx-get]`) residing within the editor panel or AI Assistant cannot trigger `closeEditor()`.
- **Safety Net Added:** Added automated regression test `StaticResourceSyntaxTest.testDashboardEditorNavigationInterceptorExemptsAiChatAndEditor` in `aura-manager/src/test/java/com/xceptance/aura/report/staticassets/StaticResourceSyntaxTest.java` asserting that `dashboard-editor.js` explicitly includes exemption rules for `#auraChatOverlay, .aura-chat-overlay, .aura-chat-launcher` and `#editorPanel`.
