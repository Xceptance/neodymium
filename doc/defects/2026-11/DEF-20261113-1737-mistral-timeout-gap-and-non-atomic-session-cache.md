# [DEF-20261113-1737] Missing Mistral Client Timeout Wiring, Unnecessary Disk Re-Parsing, and Non-Atomic Session Saves

- **Status:** `Resolved`
- **Opened:** 2026-11-13 17:37
- **Closed:** 2026-11-13 17:37
- **Component:** `aura-manager`
- **Scope:** `Framework & AI/Prompt`
- **Symptom:** The `mistral` chat provider ignored configured HTTP request timeouts (risking indefinite thread hangs), `AuraChatSessionService.getSessions()` re-read and re-parsed every cached session JSON file on every poll/refresh, and `persistSession()` truncated target `.json` files in place—risking corrupt/truncated session histories on crash or concurrent writes. Additionally, `AuraChatModelFactory.resolveModelName(...)` contained a dead duplicate `PROVIDER_GEMINI` branch.
- **Root Cause:** [`AuraChatModelFactory`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/java/com/xceptance/aura/chat/service/AuraChatModelFactory.java) did not wire a `RestClient.Builder` with `JdkClientHttpRequestFactory` read/connect timeouts into `MistralAiApi.builder()`, [`AuraChatSessionService.getSessions()`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/java/com/xceptance/aura/chat/service/AuraChatSessionService.java) called `getSession(id)` unconditionally instead of checking `sessions.containsKey(candidateId)`, and `persistSession` wrote directly to `session.id + ".json"` without a temp-file + atomic move.
- **Detection Gap ("What did we miss?"):** Unit tests only verified Gemini `HttpOptions` timeout construction and basic session JSON reload without testing Mistral `RestClient.Builder` timeout construction or leftover `.tmp` files / external disk deletions in `AuraChatSessionServiceTest`.
- **Resolution:** Added `buildMistralRestClientBuilder(Duration)` in [`AuraChatModelFactory`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/java/com/xceptance/aura/chat/service/AuraChatModelFactory.java) and wired it into `createMistralModel(...)` while removing the dead inner `PROVIDER_GEMINI` branch; updated `AuraChatSessionService.getSessions()` to validate `.json` filenames and reuse cached `ChatSessionDto` instances while evicting externally deleted `diskIds`; and updated `persistSession(...)` to write to `.json.tmp` followed by `Files.move(..., REPLACE_EXISTING, ATOMIC_MOVE)` with standard fallback and temp cleanup on `IOException`.
- **Safety Net Added:** [`AuraChatModelFactoryTest`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/test/java/com/xceptance/aura/chat/service/AuraChatModelFactoryTest.java) method `testMistralRestClientBuilderSupportsTimeoutAndNegativeTimeoutSafely` and [`AuraChatSessionServiceTest`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/test/java/com/xceptance/aura/chat/service/AuraChatSessionServiceTest.java) method `testGetSessionsEvictsExternallyDeletedFilesAndLeavesNoTempFiles`.
