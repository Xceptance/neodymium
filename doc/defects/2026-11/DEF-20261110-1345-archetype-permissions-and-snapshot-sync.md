# [DEF-20261110-1345] Archetype Shell Script Permission Loss and Local Snapshot Sync Gap

- **Status:** `Resolved`
- **Opened:** 2026-11-10 13:45
- **Closed:** 2026-11-10 13:50
- **Component:** `neodymium-archetype`
- **Scope:** `Infra/Build`
- **Symptom:**
  1. Shell script `run-aura.sh` created via `mvn archetype:generate -DarchetypeArtifactId=neodymium-archetype` lacked POSIX executable permissions (`-rw-rw-r--`).
  2. Newly implemented test `SearchTest` and page object `SearchResultPage` were missing from projects generated by `archetype:generate`.
- **Root Cause:**
  1. `maven-archetype-plugin` extracts archetype resources through standard Java I/O streams using the system umask without restoring POSIX executable bits (`+x`).
  2. `mvn verify` in the parent module builds archetype JARs into `target/` without publishing to `~/.m2/repository`. When a user runs `mvn archetype:generate`, Maven resolves from `~/.m2` where an older snapshot was cached.
  3. `maven-archetype-plugin:3.3.1` bundled an older Groovy version (3.0.21 with ASM 9.6) which failed with `java.lang.IllegalArgumentException: Unsupported class file major version 68` under JDK 24 when executing post-generation hooks.
- **Detection Gap ("What did we miss?"):**
  Archetype integration tests verified `test-compile` inside the build reactor, but did not assert POSIX execution permissions (`file.canExecute()`) on shell scripts in the generated project. Additionally, the archetype was not installed to `~/.m2` during local verification.
- **Resolution:**
  1. Added `src/main/resources/META-INF/archetype-post-generate.groovy` in `neodymium-archetype` to dynamically grant executable permissions (`runScript.setExecutable(true, false)`) to `run-aura.sh` upon project generation.
  2. Upgraded `maven-archetype-plugin` dependency to `org.apache.groovy:groovy:4.0.24` supporting modern JDK class files (up to Java 24).
  3. Executed `mvn clean install -pl neodymium-archetype` to update the local Maven repository (`~/.m2/repository/com/xceptance/neodymium-archetype/5.6.0-SNAPSHOT/`).
- **Safety Net Added:**
  Verified project generation in clean `/tmp` directory via `mvn archetype:generate`. Confirmed both `BasicTest.java` and `SearchTest.java` exist and `run-aura.sh` has executable permissions (`-rwxrwxr-x`).
