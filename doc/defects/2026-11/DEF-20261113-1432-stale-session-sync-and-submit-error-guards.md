# [DEF-20261113-1432] Stale Explicit Session Cross-Talk, Out-of-Sync Hidden Session ID, and Broken Empty/Error Submit Handling

- **Status:** `Resolved`
- **Opened:** 2026-11-13 14:32
- **Closed:** 2026-11-13 14:32
- **Component:** `aura-manager`
- **Scope:** `Framework`
- **Symptom:** Submitting a chat message referencing a deleted or missing `sessionId` silently fell back to an unrelated default session instead of opening a fresh session; `#hiddenSessionId` fell out of sync when fallback sessions were created; blank chat submissions triggered requests because `clearChatInput()` ignored return value; and HTTP 400 plain-text errors failed to render cleanly while leaving orphaned optimistic user bubbles in `#chatMessages`.
- **Root Cause:** [`AuraTestChatController.handleChat`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/java/com/xceptance/aura/test/controller/AuraTestChatController.java) called `chatSessionService.getSession(sessionId)` instead of explicit-lookup `findSession(sessionId)` when `sessionId` was provided, `fragments/chat.html` rendered `chatMessagesContent` without an OOB `#hiddenSessionId` update and used `onsubmit="clearChatInput()"`, and [`dashboard-core.js`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/resources/static/dashboard-core.js) only parsed JSON `{ error }` while leaving `.optimistic-user-bubble` elements untouched on `htmx:responseError`.
- **Detection Gap ("What did we miss?"):** Controller unit tests previously mocked `getSession(...)` for missing IDs without distinguishing explicit-missing lookups from null session initialization, and no Node/template check guarded empty form cancellation or `#hiddenSessionId` OOB sync.
- **Resolution:** Updated `AuraTestChatController.handleChat` to resolve explicit `sessionId` via `findSession(sessionId)` and create a fresh `"New Chat"` session with `oobSessionSelect = true` when missing, added an OOB `<input type="hidden" id="hiddenSessionId" hx-swap-oob="outerHTML"/>` inside `chatMessagesContent` in [`chat.html`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/resources/templates/fragments/chat.html), updated `onsubmit="return clearChatInput(event)"` with `preventDefault()` + `htmx:beforeRequest` empty guard and `.optimistic-user-bubble` marker in [`dashboard-chat.js`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/main/resources/static/dashboard-chat.js), and consolidated `htmx:responseError` handling in `dashboard-core.js` to display non-HTML `xhr.responseText` and clear both `.thinking-bubble` and `.optimistic-user-bubble`.
- **Safety Net Added:** [`AuraTestChatControllerTest`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/test/java/com/xceptance/aura/chat/controller/AuraTestChatControllerTest.java) methods `testHandleChatCreatesFreshSessionInsteadOfMutatingDefaultWhenExplicitSessionMissing`, `testChatTemplateIncludesOobHiddenSessionIdAndSafeSubmitGuards`, and `testDashboardCoreHandlesPlainTextErrorAndCleansOptimisticUserBubble`; [`DashboardChatJsTest`](file:///home/robert/Development/internal/neodymium/neodymium/aura-manager/src/test/java/com/xceptance/aura/chat/DashboardChatJsTest.java) verifying `clearChatInput(event)` calls `preventDefault()` and returns `false`.
