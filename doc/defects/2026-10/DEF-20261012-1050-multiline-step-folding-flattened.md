# [DEF-20261012-1050] Multi-Line Folded Block Scalar Steps Flattened During Parsing and Visual Editor Display

- **Status:** `Resolved`
- **Opened:** 2026-10-12 10:50
- **Closed:** 2026-10-12 11:22
- **Component:** `neodymium-core` & `aura-manager`
- **Scope:** `Framework`
- **Symptom:** In tests utilizing multi-line steps written with YAML folded block scalars (`- >` or `- >-`, e.g. self-including verification step blocks), the Visual Editor displayed all lines collapsed into a single run-on step row paragraph. Furthermore, test execution parsed the entire block into a single flattened step containing all concatenated assertions, causing AI pre-flight linter warnings (`STEP_SPLITTING_CANDIDATE`) and preventing discrete step-level execution, reporting, and healing.
- **Root Cause:** In standard YAML 1.2 (§8.1.3), folded block scalars (`>`) replace each non-empty line break with a single space. When SnakeYaml loaded the file, the parsed string was flattened with whitespace before reaching Neodymium or Aura Manager. Consequently, `AuraFileService.parsePlaybookSections()` treated it as a single scalar item in `mainSteps`, rendering only one `.step-row`, and `YamlPlaybookParser.parseStepBlock()` received a single-line string with no newline delimiters to split into discrete `PlaybookStep` instances.
- **Detection Gap ("What did we miss?"):** Unit tests in `YamlPlaybookParserTest` and `AuraFileServiceTest` only tested discrete list items (`- step 1\n- step 2`) or literal step fragments, but never asserted parsing of multi-line folded scalar syntax (`- >` / `- >-`) or nested map structures (`- Header:\n  - Substep`).
- **Resolution:** Added `AuraFileService.normalizeBlockScalars` using regex to convert step-level folded block scalars (`>` and `>-`) to literal block scalars (`|` and `|-`) before SnakeYaml parsing in both `AuraFileService.parsePlaybookSections()` and `YamlPlaybookParser` (`parseInternal()` and `parseRecursive()`). In `AuraFileService`, introduced `parseSectionSteps()` to split multi-line string steps into discrete entries and support hierarchical single-entry mapping sub-step lists.
- **Safety Net Added:** `AuraFileServiceTest.testParsePlaybookSectionsWithFoldedBlockScalarSteps`, `AuraFileServiceTest.testParsePlaybookSectionsWithFoldedBlockScalarChompedSteps`, `AuraFileServiceTest.testParsePlaybookSectionsWithLiteralBlockScalarSteps`, `AuraFileServiceTest.testParsePlaybookSectionsWithHierarchicalMapSubSteps`, `YamlPlaybookParserTest.testParsePlaybookWithFoldedBlockScalarSteps`, `YamlPlaybookParserTest.testParsePlaybookWithFoldedBlockScalarChompedSteps`, `YamlPlaybookParserTest.testParsePlaybookWithLiteralBlockScalarSteps`, and `AuraManagerEditorUiTest.testOpenFoldedScalarStepsRendersDiscreteRowsInVisualEditor`.
